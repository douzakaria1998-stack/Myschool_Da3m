# Da3m (دعم) Education Management System 📚

نظام متكامل لإدارة مراكز الدروس الخصوصية والتعليمية (الأفواج، تسجيل حضور التلاميذ، اقتسام الأتعاب مع الأساتذة، ومراقبة مداخيل المركز).

تم بناء هذا النظام باستخدام **Next.js 15+** و **Google Material Design 3 (M3)**.

## 🚀 التشغيل المحلي (Getting Started)

1. تثبيت الحزم:
```bash
npm install
```

2. تشغيل خادم التطوير:
```bash
npm run dev
```

افتح [http://localhost:3000](http://localhost:3000) في المتصفح.

## ✨ المميزات الرئيسية
- 📋 **إدارة الأفواج العادية و VIP**: متابعة حصص الفوج، عدد الحصص، وأفواج اليوم مع ميزة تجديد الفوج ونقل تلاميذ الحصة الأولى تلقائياً.
- 👨‍🎓 **سجل وبيانات التلاميذ الشامل**: بطاقات تفصيلية، نسب الحضور، الديون، وأرقام الهواتف مع التصدير إلى Excel/CSV.
- 🧾 **الوصولات الحرارية (80mm)**: طباعة وصولات حرارية متوافقة مع طابعات الإيصالات.
- 👨‍🏫 **حساب مستحقات الأساتذة وحصة المركز**: حساب آلي دقيق لتقاسم المداخيل حسب خطط التسعير.
- 🔒 **حماية الخصوصية**: إمكانية إخفاء/إظهار الإحصائيات المالية في أي وقت.
